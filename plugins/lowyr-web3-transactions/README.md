# lowyr-web3-transactions

Commercial and corporate toolkit for blockchain businesses: web3 contract drafting with a token-aware clause library, market-making agreement review against market-abuse rules, and group/jurisdiction structuring.

Part of the [lowyr](../../README.md) marketplace by Bastien Choquez.

## Install

```
/plugin marketplace add lawgic-ally/lowyr
/plugin install lowyr-web3-transactions@lowyr
```

## Skills

| Skill | Purpose |
|---|---|
| `market-maker-agreement-reviewer` | Review, negotiate or draft crypto market-making and liquidity-provision agreements — token loan + call option structures, retainer/fee models, KPIs (spread, depth, uptime, venue coverage), reporting and audit rights, conflicts and information barriers — and test them against market-abuse rules (MiCA Title VI, Arts 86–92), venue rules and sanctions/AML, from either the issuer's or the market maker's side. |
| `web3-commercial-drafter` | Draft, review and negotiate commercial and technology agreements for blockchain businesses — MoUs and term sheets, strategic partnership and co-marketing agreements (incl. sports, media and brand partnerships), token listing agreements, technology/IP licences, SaaS and API agreements with on-chain components, validator/node operator and infrastructure agreements, integration and white-label agreements — using a web3-specific clause library (token volatility, regulatory change, chain events, smart-contract failure, sanctions, custody, data on-chain). |
| `web3-entity-structurer` | Design or review the corporate and regulatory structure of a blockchain group — where to place the token issuer/foundation, operating company, licensed CASP/VASP, IP holder, treasury, proprietary trading or market-making entity, and service companies — comparing jurisdictions (e.g. EU Member States under MiCA, Switzerland, Cayman Islands, BVI, UAE (VARA, ADGM, DIFC, free-zone DAO regimes), Singapore, UK) on licensing, substance, governance, banking, and flagged tax touchpoints, and produce a structure chart and memo. |

Every skill re-verifies statutory references against primary sources at run time. The verified baseline is in [docs/citation-register.md](../../docs/citation-register.md). Not legal advice; see [DISCLAIMER.md](../../DISCLAIMER.md).
