# lowyr-protocol-legal

Where law meets code: map smart-contract control surfaces to legal exposure (decentralisation, custody, disclosure, liability), plus a dual legal/technical Web3 expert for fundraising instruments, DAO structures, US securities analysis and security audits.

Part of the [lowyr](../../README.md) marketplace by Bastien Choquez.

## Install

```
/plugin marketplace add lawgic-ally/lowyr
/plugin install lowyr-protocol-legal@lowyr
```

## Skills

| Skill | Purpose |
|---|---|
| `protocol-legal-review` | Read smart-contract code (Solidity/Vyper/Rust) or protocol documentation and translate technical control features — admin/owner keys, upgradeability proxies, pause/freeze, mint/burn authority, blacklists, fee switches, oracles, bridge validators/relayers, multisigs, governance and timelocks, front-end gating — into legal consequences, namely decentralisation claims (MiCA Recital 22), custody and transfer-service characterisation, issuer/offeror identification, white-paper and marketing disclosure gaps, sanctions/AML capability, and liability. |
| `web3-legal-expert` | Dual-authority Web3 legal and technical expert — a blockchain lawyer and protocol engineer in one — and the front door to this marketplace. |

Every skill re-verifies statutory references against primary sources at run time. The verified baseline is in [docs/citation-register.md](../../docs/citation-register.md). Not legal advice; see [DISCLAIMER.md](../../DISCLAIMER.md).
