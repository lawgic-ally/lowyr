## Verification method

1. Primary text located on EUR-Lex / legislation.gov.uk or the ESMA Interactive Single Rulebook.
2. Article number and heading confirmed against at least one independent consolidated source.
3. Anything that could not be confirmed against a primary or regulator source was **not** hard-coded; skills instead instruct the model to locate and read the provision at run time.
